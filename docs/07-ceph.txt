## Problems hit
- pve1's first pveceph install was interrupted and left only the Ceph client libraries: ceph-mon, ceph-osd, ceph-mgr and ceph-base were missing. apt full-upgrade did NOT fix it, because upgrade only touches packages that are already installed. Re-running pveceph install resolved it
- Ceph version differed between nodes (19.2.3 Squid on pve1, 20.2.4 Tentacle on pve2/pve3) from the same repository; evened up before pveceph init
- Ctrl+C on a gcloud ssh --command kills the local command but not the remote process: apt kept running and held the dpkg lock, causing "Could not get lock /var/lib/dpkg/lock-frontend" on the retry
